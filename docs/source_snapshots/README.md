# Management extension source snapshots

These standalone C snapshots document the incremental implementation of the management extension:

1. `P1_SOA_step11_priority.c` — priority ranking and criticality scoring
2. `P1_SOA_step12_recommended_action.c` — recommended actions by safety status
3. `P1_SOA_step13_management_summary.c` — portfolio-level management KPIs and `management_summary.csv`

They accompany development reports 11–13 and preserve the implementation history of the extension.
